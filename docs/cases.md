# Кейси

П’ять інструментів з цього репозиторію — по одному абзацу на задачу: що було, що зробив, що вийшло. Усі цифри з реальних запусків; перевірити можна командами з кожного кейсу.

## 1. Монітор нових замовлень freelance.ua

**Задача.** Вручну гортати список замовлень кілька разів на день і вичитувати, чи є щось про Python, боти чи парсинг. Частина замовлень зникає з першої сторінки за кілька годин, а перші пропозиції отримують непропорційно більше відповідей.

**Рішення.** `freelance_monitor.py` читає відкритий список (без входу в акаунт), розбирає картки, фільтрує локально за ключовими словами, бюджетом і свіжістю, прибирає дублі в SQLite (щоб те саме замовлення не приходило двічі), пише CSV та HTML-звіт і надсилає кожне нове замовлення окремим повідомленням у Telegram.

**Результат.** Живий прогін: 3 сторінки → 30 замовлень → 6 пройшли фільтри. Демо на збереженій сторінці: 10 замовлень розібрано, 0 сторонніх залежностей. Фільтри й дедуплікація покриті тестами.

```bash
python freelance_monitor.py --demo --all --html out/demo/orders.html
```

## 2. Монітор тендерів Prozorro

**Задача.** Не пропустити закупівлю свого профілю серед тисяч оголошень і не читати ті, що не підходять за сумою, регіоном чи кодом ДК.

**Рішення.** `prozorro_monitor.py` бере відкритий API (без ключа), фільтрує за ключовими словами, кодом ДК 021, діапазоном суми й регіоном, прибирає вже бачені тендери, формує CSV/HTML і шле сповіщення в Telegram.

**Результат.** Один прогін переглядає найновіші 100 карток (`--inspect`), налаштовується JSON-конфігом; на фікстурі з 6 реальних тендерів розбір і фільтри працюють офлайн.

```bash
python prozorro_monitor.py -k ремонт --inspect 60 --csv out/tenders.csv --html out/tenders.html
```

## 3. Звіт із банківської виписки

**Задача.** Перетворити CSV-виписку на зрозумілі підсумки за категоріями — без Excel-макросів і ручного перекладання.

**Рішення.** `bank_report.py` визначає формат файлу, нормалізує суми й дати, групує транзакції за правилами з `category_rules.json`, рахує підсумки та середній чек, пише `summary.txt`, `report.csv` і `report.html`.

**Результат.** На синтетичній виписці на **7 500 транзакцій** (листопад 2023 — листопад 2026, 17 мерчантів): повний звіт за **0,4–0,8 с** — три файли `summary.txt`, `report.csv`, `report.html`; витрати 6 657 748,20 UAH, надходження 2 990 994,30 UAH, середній чек 915,15 UAH, 10 категорій. Категорії розширюються одним JSON-файлом, без правки коду.

```bash
python tools/make_statement.py --rows 7500 --out out/bench_statement.csv   # синтетика, seed фіксований
python bank_report.py out/bench_statement.csv --out out/bench             # -> summary.txt, report.csv, report.html
python bank_report.py sample_statement.csv                                # маленький приклад із репозиторію
```

## 4. Telegram-бот запису на послуги

**Задача.** Клієнти пишуть у різні месенджери, частина записів губиться, а подвійний запис на один слот з’ясовується вже на місці.

**Рішення.** `booking_bot.py` — бот із вільними слотами, підтвердженням і скасуванням клієнтом; стан діалогу в пам’яті процесу, записи в SQLite. Подвійний запис на слот відхиляється на рівні логіки, скасувати чужий запис не можна.

**Результат.** Повний діалог запису відтворюється без токена (`--demo`), обидва захисти — від подвійного запису й від скасування чужого запису — покриті тестами.

```bash
python booking_bot.py --demo
```

## 5. Пошук компаній для холодних контактів

**Задача.** Знайти бізнеси, які регулярно виграють державні закупівлі, — тобто мають бюджет і повторювані процеси.

**Рішення.** `prospect_finder.py` бере підписані договори з відкритого API Prozorro, зіставляє «об’єкт закупівлі → переможець», агрегує по компаніях суми й кількість перемог, сортує за грошима і пише CSV/HTML з колонками `contact`/`status` для ведення контактів.

**Результат.** На фікстурі: 8 договорів → 8 зв’язок «об’єкт → переможець» → 5 компаній, відсортованих за сумою; на живому API — до 200 договорів за один прогін.

```bash
python prospect_finder.py --demo --out out/demo/prospects
python prospect_finder.py --days 21 --limit 200 --min-amount 100000 --top 40
```
